## 认证证据

`IdentityPrincipal.authenticatedAt` 保持原始 IAM 登录时间，继续约束一天 SSO、原始刷新绝对寿命以及 RP sid/退出映射。新增 `authenticationMethod` 与可空 `passwordAuthenticatedAt`。目录登录记录 PASSWORD 与密码验证时间；未来 FEISHU principal 缺省没有密码证据。OTP 只增加 MFA 证据，不能制造密码证据。安全上下文由服务器构造，不从 API 请求接收这些字段。

token 的 amr 按实际证据生成：密码为 pwd，预留飞书来源为 feishu，OTP 为 otp；没有密码证明时不能标注 pwd。新 principal 保留可空密码字段；旧版本服务写入的 principal 缺少来源字段时，按原有纯目录密码登录解释，保持原时间，不延长五分钟证明。旧数据只能来自受保护的服务数据库/Redis，不能导入不可信安全上下文。新源码的 FEISHU 表示与测试夹具不等于已经实现免登。

后续启用联邦会话前必须升级所有消费安全上下文的 IAM 节点。旧版本会忽略新增字段并沿用纯密码语义，不允许启用后与旧节点混跑或直接回退；回退需先停用联邦入口、撤销新来源会话及授权并重新做目录登录。实际集群发布门禁仍需随 T5/T11 落实。

当前 IAM Redis 使用 Spring Session 默认的 JDK 序列化，授权表使用 Jackson JSON。旧 Java stream 缺少新字段时不会执行 JSON 构造器，因此通过 readResolve 恢复原来的 PASSWORD 与原密码时间；新 FEISHU stream 保留空密码证据。两种存储格式分别验证，不从 JSON 单测推断 Redis 兼容性。

自助改密、MFA 初始注册/确认、因素轮换与恢复、管理员改密/恢复/状态读取均要求真实密码时间在当前时刻之前且未满五分钟。OTP 与登录会话新鲜不能代替此条件；原有实时角色、epoch、gate、MFA 和恢复限制继续生效。密码操作自己的受限状态查询使用密码证明时间，支持旧会话再认证后查询自身 fenced 操作，不放宽其他路由。

## 同会话再认证

`POST /api/session/reauthenticate`，请求体 `{"password":"<当前目录密码>"}`，要求有效会话及 CSRF。不会接收目标账号、用户名、epoch 或角色。目录身份与账号来自当前 principal 和 PG；共用登录的账号/IP 限流。凭据错误返回 401，限流 429，目录/状态服务不可用 503，详细密码或依赖异常文本不返回客户端。

先确认当前账户可用，再在数据库事务外验证 LDAPS 凭据；成功后短事务锁定身份并再次检查 epoch/gate/Redis 安全代次，记录 PASSWORD_REAUTH_SUCCESS，再返回新 principal。目录验证期间禁用、改密或恢复 fence 会拒绝升级。输入 char[] 在成功和异常路径清零。失败记录不保存口令。

成功更新密码证据并刷新实时角色，保留用户、epoch、来源、原始登录与 MFA 时间。控制器更换 session ID、移除旧 MFA context、保存安全上下文，返回 `{"verified":true}`。此入口不会解除密码 gate、must_change_password 或 MFA recovery 限制，也不延长原始会话寿命；到期或已被 fence 的旧会话必须重新登录。

OpenAPI 新增此路径，业务接口现为 25 个路径。完整 IAM 门户的输入/提示/错误页仍属于 T7；此入口先提供可调用后端。
