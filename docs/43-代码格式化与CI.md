# 代码格式化与 CI（Spotless + Google Java Format）

> 本文记录 2026-10-31 的格式化接入。Maven 主线已强制；Gradle 分支尚未改动（按既定分工由 Codex 合并时补等价配置）。

## 1. Maven 配置

根 pom.xml：

- com.diffplug.spotless:spotless-maven-plugin:2.43.0
- google-java-format:1.22.0（GOOGLE style）
- 覆盖 src/main/java/**/*.java 与 src/test/java/**/*.java
- trimTrailingWhitespace、endWithNewline
- spotless-check 绑定 validate（先于编译/测试失败，CI 反馈快）

.mvn/jvm.config（JDK 17 运行 GJF 必需）：

~~~text
--add-exports=jdk.compiler/com.sun.tools.javac.api=ALL-UNNAMED
--add-exports=jdk.compiler/com.sun.tools.javac.file=ALL-UNNAMED
--add-exports=jdk.compiler/com.sun.tools.javac.parser=ALL-UNNAMED
--add-exports=jdk.compiler/com.sun.tools.javac.tree=ALL-UNNAMED
--add-exports=jdk.compiler/com.sun.tools.javac.util=ALL-UNNAMED
~~~

## 2. 本地命令

~~~powershell
mvn spotless:apply     # 格式化
mvn spotless:check     # 只检查
~~~

## 3. CI

.github/workflows/maven.yml 执行：

~~~text
mvn --batch-mode --no-transfer-progress clean verify -Pintegration -Dtest.redis.executable=/usr/bin/redis-server
~~~

由于 spotless-check 绑定 validate，CI 在编译/测试前先对每个模块运行 spotless:check；未格式化会直接失败。CI 不会自动提交格式化结果，格式化由开发者在本地 spotless:apply 后提交。

已验证：run 41163633622（head 1b99f27）日志中 spotless:2.43.0:check 在 unipass/iam-directory/iam-identity/iam-password/iam-portal/iam-server/iam-web 全部执行，workflow success。

## 4. Gradle 分支（未做）

UniPass-gradle 目前没有 Spotless。合并主分支后需在 Gradle 侧补等价配置，例如：

~~~groovy
plugins {
    id 'com.diffplug.spotless' version '6.25.0'
}
subprojects {
    apply plugin: 'com.diffplug.spotless'
    spotless {
        java {
            googleJavaFormat('1.22.0')
            trimTrailingWhitespace()
            endWithNewline()
        }
    }
}
~~~

并在 gradle.properties 的 org.gradle.jvmargs 中加入与 .mvn/jvm.config 相同的 --add-exports。CI 的 Gradle workflow 应执行 ./gradlew spotlessCheck build（或不自动 apply，只 check）。这部分按既定分工由 Codex 在 Gradle 分支完成并验证；本轮未改 sibling。
