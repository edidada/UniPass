## P1 已实现

- `iam-directory`：只接受 LDAPS，JVM 信任链及主机名校验，非匿名绑定，稳定 ID 查询、凭证验证、用户改密和禁用；AD 的 objectGUID 字节序、用户改密 delete/add、UAC 保留及断言控制已编码。
- `iam-identity`：PG/Flyway 初始迁移、严格 CSV 字段、持久化 staging、校验摘要去重、预览与显式确认、无效行隔离、游标与身份变更同事务提交、版本与归属冲突拒绝。
- 离职先在本地持久化 DISABLED/BLOCKED 并递增 auth_epoch，再生成可重试目录任务；Worker 短事务领取，网络调用不持数据库锁，使用租约令牌防止过期结果覆盖。
- 操作员 CLI 支持 migrate/preview/report/apply/disable/reconcile；未暴露无鉴权 HTTP 管理接口。导入不自动创建目录账号、不自动重新激活禁用账号、不按缺失行删除账号。
