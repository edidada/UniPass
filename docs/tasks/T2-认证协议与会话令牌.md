## 1. 目标与边界

承接 [PM 任务规划](../05-PM开发子任务规划与里程碑.md) 的 T2。公共技术决策见 [技术选型](../08-技术选型与决策记录.md)，跨文档口径见 [设计基线](../09-设计基线与待确认事项.md)。本文的完成标准必须以交付证据验证，不能以文档完成代替实现完成。

## 2. 处理流程与实现约束

1. OIDC 发现地址、JWKS、authorize、token、userinfo、revoke、logout 采用成熟框架；端点别名在框架层配置，禁止手写协议签名与解析。
2. 所有交互客户端走授权码 + S256 PKCE；公共客户端不发 secret，机密客户端默认 basic 或 private_key_jwt。精确校验 redirect_uri、issuer、audience 和 scope。
3. 授权码上下文绑定 client_id、redirect_uri、challenge、nonce、sid，60 秒过期；先验证客户端与上下文，再原子消费，竞争请求仅一个成功。
4. Refresh token 保存摘要及 family_id、parent_id、expires_at、used_at、auth_epoch；事务行锁完成轮换，复用旧值吊销整族。SDK 将同设备刷新请求合并。
5. JWT 携带 auth_epoch（单调递增整数），资源服务每次请求校验账号状态和 epoch，允许缓存最多 5 秒；状态查询失败拒绝请求。仅验证签名不能满足即时吊销。
6. SSO Cookie 限 IAM 主机，跨应用通过重定向复用会话；不把 sid 返回给前端脚本。MFA 挑战绑定用户、授权上下文和有效期，一次使用。
7. SAML IdP 是单独的框架能力验证项，不能将 SAML SP 客户端当成 IdP。CAS/RADIUS 不在首期实现；确有试点依赖再变更范围。
8. V6 PG 控制行串行恢复 Redis generation/run_id；不一致时拒绝旧认证，恢复递增 OPEN 身份 epoch 并撤销族。Redis 写成功而 PG 提交失败仍拒绝认证。BLOCKED 操作保留 fenced epoch，避免破坏人工密码恢复。
9. 外置 PKCS12 重叠发布旧/新公钥，只有当前 alias 加载私钥；发布、切签名与退役分步重启，退役等待令牌有效期及 RP 缓存窗口。现有本地双 key 测试不能替代多节点/RP 轮换验收。
10. V7 因素轮换先保留旧因素，确认新因素才原子替换并 fence。管理员恢复必须独立操作员、实时 MFA_RECOVERY 权限、近期密码/MFA、原因与证据；恢复凭证摘要保存、一次消费并绑定目标 epoch，用户重新登录后在同浏览器确认新因素。恢复中禁止普通注册和令牌签发，取消或过期不降级。详见 [因素生命周期](../18-MFA因素轮换与受控恢复.md)。
11. V8 身份 fence/授权撤销与 back-channel 入队同事务，持久任务按租约领取、有限重试，每次重新签发 jti。RP 校验签名/issuer/audience/type/events/时间、sid/sub 和 jti，原子删除会话并保留 sid 吊销标记。仅登记机密 Web RP 接收，详见 [退出通知](../21-OIDC后端退出通知.md)。
12. V9 对 MFA 加密 key 增加 PG writer、材料指纹和退役控制，V1/V2 兼容读取；新旧节点不能在激活后写回旧格式。分批重加密保留因素状态、OTP 时间步与 epoch，坏密文或提交失败整批回滚，退役要求无引用并验密。见 [主密钥轮换](../22-MFA加密主密钥轮换.md)。

## 3. 数据与契约

会话含 sid、user_id、client_id、auth_epoch、created_at、last_seen_at、absolute_expires_at；滑动 8 小时另设绝对上限。refresh 摘要唯一，禁止原始 token 进入 DB、Redis key、日志。

字段与接口以 [公共详细设计](../04-详细设计文档.md) 为起点；新增表和字段必须配数据库迁移及回退兼容说明。内部 ID 采用不可变 UUID，时间统一 UTC，日志回传 trace_id；业务错误使用公共错误信封，协议错误遵循对应协议。

## 4. 异常处理与运维

依赖调用设置连接与总超时，不无限重试；写入结果不明时保留 operation_id 与可恢复状态。关键指标按任务、结果和依赖统计，禁止以用户 ID 作为高基数指标标签。认证、授权和状态校验故障均拒绝放行；管理员操作和人工修复必须留审计。

## 5. 验证与完成标准

授权码并发消费、PKCE 错误、精确回调、refresh 并发与复用、JWKS 轮换、禁用后签发竞争、Redis 丢失后旧令牌重放。

交付物：协议配置、OpenAPI（仅业务接口）、RP 示例、自动化安全用例、吊销时延报告；对应 A1、A4、A5。

开发自测、QA 验证和责任人评审分别记录 commit、执行时间、环境与证据位置；未执行填“未执行”，不得预填通过。

独立 RP 增量：`iam-web` 使用成熟 OAuth2 client，资源端调用标准 introspection 完成 live epoch/gate/族检查，不共享 IAM 数据库。双 RP 独立进程测试已覆盖 SSO、刷新、改密与退出，真实 HTTPS 跨主机浏览器和 P99 五秒时延仍待验收，见 [接入记录](../19-独立Web应用与BFF接入.md)。
