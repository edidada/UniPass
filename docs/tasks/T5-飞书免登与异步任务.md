## 1. 目标与边界

承接 [PM 任务规划](../05-PM开发子任务规划与里程碑.md) 的 T5。公共技术决策见 [技术选型](../08-技术选型与决策记录.md)，跨文档口径见 [设计基线](../09-设计基线与待确认事项.md)。本文的完成标准必须以交付证据验证，不能以文档完成代替实现完成。

## 2. 处理流程与实现约束

1. 建立 capability 表：免登、通讯录读取、外部会话撤销分别保存权限、API 官方链接、测试租户和验证时间。未验证的写密码与撤销能力默认关闭。
2. 服务端以一次性授权凭据换身份，校验应用、租户和有效期，按(tenant_id, external_user_id)查绑定。首次绑定要求 IAM 近期认证，禁止只凭邮箱匹配。
3. 改密提升 auth_epoch 后，飞书打开的 UniPass 应用必须要求 IAM 近期认证；旧飞书身份凭据不可自动绕过改密门禁。
4. 只处理不含口令的 PASSWORD_CHANGED/USER_DISABLED 事件。没有外部撤销能力时，只报告 UniPass 应用访问已撤销；不得报告飞书客户端全局登出成功。
5. Worker 用 PG SKIP LOCKED 短事务领取到期任务并写租约，事务外调用外部服务，再用租约版本 CAS 回写；宕机由租约超时重领。
6. 唯一(event_id,target)防重复任务；外部支持幂等键则透传 event_id，不支持则按至少一次处理并核对最终状态，不能保证外部调用恰好一次。
7. 可重试错误退避 1/5/15 分钟加抖动；429 遵循 Retry-After，权限错误进 BLOCKED，耗尽进 DEAD 并告警。能力缺失不是成功；SUCCESS_DEGRADED 仅用于已证实的替代结果。

## 3. 数据与契约

sync_task 增加 lease_owner、lease_until、lease_version、next_retry_at；outbox 保存 event_id、schema_version、payload、published_at。外部绑定唯一(tenant_id,external_user_id)。

V10 实现记录见 [持久同步任务](../23-持久同步任务与死信恢复.md)：复用 V2 lease_token，并增加 owner/version、结果时间和任务审计。已接入 PASSWORD_CHANGED 与 USER_DISABLED 的同事务 fan-out；published_at 表示任务持久化，不能表示外部投递。未注册的飞书/推送投递目标明确 BLOCKED，生产投递适配器与外部对账仍未实现。

接入前的 [认证来源与密码再认证](../24-认证来源与密码再认证.md) 已编码：第三方身份/OTP 不生成 pwd 证据，敏感操作独立检查真实密码时间；同会话再认证不延长原始登录或改变 epoch。

V11 [飞书登录与显式绑定](../25-飞书登录与显式绑定.md) 实现固定单应用/租户 OAuth v3、S256、浏览器归属的五分钟 state、一次性 code、显式绑定、bound_epoch、实时能力与到期检查。默认关闭；操作员离线记录 LOGIN 核验引用，有效最多七天。改密后先真实密码登录并完成所需 MFA，再续绑；删除绑定或能力变更递增 epoch 并撤销已有授权。CONTACT_READ 未验证，外部撤销/密码写入不可用；测试替身不代替真实 POC-03。

字段与接口以 [公共详细设计](../04-详细设计文档.md) 为起点；新增表和字段必须配数据库迁移及回退兼容说明。内部 ID 采用不可变 UUID，时间统一 UTC，日志回传 trace_id；业务错误使用公共错误信封，协议错误遵循对应协议。

## 4. 异常处理与运维

依赖调用设置连接与总超时，不无限重试；写入结果不明时保留 operation_id 与可恢复状态。关键指标按任务、结果和依赖统计，禁止以用户 ID 作为高基数指标标签。认证、授权和状态校验故障均拒绝放行；管理员操作和人工修复必须留审计。

## 5. 验证与完成标准

授权码重放、跨租户绑定、权限回收、429、响应丢失、租约过期双 Worker、重复事件；离职回调先验签再落库，持久化后 ACK。

交付物：能力探测报告、免登适配器、重试与死信管理、对账报告；对应 A3、A5-5。

开发自测、QA 验证和责任人评审分别记录 commit、执行时间、环境与证据位置；未执行填“未执行”，不得预填通过。
